# Платформа подбора роботизированных решений

> Хакатон «Лидеры цифровой трансформации» (ЛЦТ) 2026 — конкурс Мэра Москвы.

## Описание

Веб-платформа для экспресс-предвынвестриционной оценки роботизации объектов: складов, аэропортов, медицинских учреждений и других типов объектов.

Платформа позволяет пользователю пройти путь из 4 шагов:

1. **Выбор объекта** — выбор отрасли и типа объекта с демонстрационными данными
2. **Подбор решений** — каталог роботизированных решений с фильтрацией, поиском и сравнением
3. **Расчёт экономики** — ввод параметров объекта, расчёт CAPEX/OPEX/ROI/срока окупаемости, анализ чувствительности (What-if)
4. **Визуализация** — имитация работы роботов на схеме объекта с отображением KPI в реальном времени

## Быстрый старт

### Требования

- Node.js >= 20
- npm >= 10

### Запуск

```bash
npm install
npm start
```

Платформа доступна по адресу `http://localhost:3000`.

### Демо-аккаунты

- Администратор: `admin@robplatform.local` / `admin123`
- Пользователь: `demo@robplatform.local` / `demo123`
- Гость: вход не требуется (только просмотр каталога и демо-расчётов)

### Docker

```bash
docker-compose up
```

## Основные функции

### Пользовательские роли

| Роль | Доступ |
|---|---|
| Гость | Просмотр каталога, демо-расчёты |
| Пользователь | Создание, редактирование, сохранение проектов, расчёт, визуализация, экспорт |
| Администратор | Управление каталогом, пользователями, параметрами, импорт данных |

### Экономическая модель

- **CAPEX**: оборудование + инфраструктура + ПО + интеграция + обучение + резерв
- **OPEX**: сервис + лицензии + электроэнергия + материалы + ремонт + управление
- **Годовой эффект**: сокращение затрат на труд + рост производительности
- **ROI**: накопленный эффект / инвестиции × 100%
- **TCO**: CAPEX + сумма OPEX за расчётный горизонт с учётом замены компонентов
- **Чувствительность**: вариация ключевых параметров (±10%, ±20%) для трёх факторов

### Сценарии сравнения

Платформа сравнивает:
1. Базовый сценарий (без роботизации)
2. Сценарий покупки оборудования (CAPEX + OPEX)
3. Сценарий «Роботы как услуга» (аренда / RaaS)

## Данные

### Демо-данные

- **Каталог**: 224 позиции из `catalog_export_v4.csv` (ФЦ БАС каталог)
- **Датасеты**: параметры объектов из `Датасеты_хакатон.xlsx` для складов, аэропортов, медучреждений
- **Объекты**: склад, торговый зал, аэропорт, терминал, медучреждение, кампус/МФЦ, произвольный объект
- **Новые отрасли (добавлены)**: сельское хозяйство (ферма), ЖКХ/муниципальное хозяйство, строительство (стройплощадка), ТЭК/энергетика (энергообъект), лесное хозяйство, охрана/безопасность, производство
