# Платформа подбора роботизированных решений

> Хакатон «Лидеры цифровой трансформации» (ЛЦТ) 2026 — конкурс Мэра Москвы.

## Описание

Веб-платформа для экспресс-предынвестиционной оценки роботизации объектов: складов, аэропортов, медицинских учреждений, производств и других типов объектов.

Платформа позволяет пользователю пройти путь из 4 шагов — от выбора объекта до готового отчёта с формальными результатами:

1. **Выбор объекта** — выбор отрасли и типа объекта, а также **чат-помощник**, который распознаёт тип предприятия по описанию («склад», «аэропорт», «больница», «ферма»…) и задаёт уточняющие вопросы (площадь, объём операций, персонал, зарплата)
2. **Подбор решений** — каталог роботизированных решений с фильтрацией, поиском, сравнением и **ИИ-подбором** (включая локальный fallback без сервера)
3. **Расчёт экономики** — ввод параметров объекта, **конфигуратор математической модели** (коэффициенты CAPEX/OPEX), **чат-помощник по модели**, расчёт CAPEX/OPEX/ROI/срока окупаемости, анализ чувствительности (What-if)
4. **Формальные результаты** — итоговый отчёт: резюме проекта, ключевые показатели, сравнение сценариев, детализация CAPEX/OPEX, допущения модели, экспорт и печать

## Ключевые возможности

### 🤖 Чат-помощник на шаге 1 (выбор объекта)
- Распознавание типа предприятия по ключевым словам: склад, аэропорт, больница, ферма, стройплощадка и др. (13 типов объектов)
- Уточняющие вопросы: площадь → объём операций → численность персонала → средняя зарплата
- Значения автоматически подставляются в параметры расчёта

### 🧠 ИИ-подбор решений (шаг 2)
- Ранжирование решений по экономической эффективности, соответствию параметрам объекта и текстовому совпадению
- Работает через серверный `/api/recommendations`, а при недоступности сервера — **локальный fallback** прямо в браузере из `HACKATHON_DATA`
- Панель рекомендаций сохраняется после перерисовки, добавленные решения помечаются «✓ Добавлено»

### 📌 Закреплённая панель действий (шаг 2)
- Кнопка «Далее: Расчёт экономики» всегда на виду (sticky-панель внизу экрана)
- Счётчик выбранных решений (до 3) и быстрый переход к блоку сравнения

### ⚙️ Конфигуратор математической модели (шаг 3)
- Тонкая настройка коэффициентов: инфраструктура, ПО, интеграция, обучение, резерв (CAPEX); сервис, лицензии, материалы, ремонт, управление (OPEX)
- Кнопка сброса к стандартным значениям

### 💬 Чат-помощник по математической модели (шаг 3)
- Понимает команды: «увеличь затраты на обучение», «больше интеграции», «сделай модель консервативнее», «быстрее», «покажи коэффициенты», «сброс к стандартной»
- Изменения сразу влияют на расчёт

### 📋 Формальные результаты (шаг 4)
- Резюме проекта, ключевые показатели, сравнение сценариев (без роботизации / покупка / RaaS / кредит)
- Детализация CAPEX и OPEX, допущения модели
- Экспорт расчёта (TXT + HTML) и печать / PDF

### 🎨 Профессиональный интерфейс
- Приглушённая корпоративная палитра (глубокий синий primary, нейтральные фоны, мягкие тени)
- Адаптивная вёрстка: шаги, карточки, таблицы и sticky-панель корректно работают на мобильных устройствах

## Быстрый старт

### Требования

- Node.js >= 20
- npm >= 10

### Запуск

```bash
npm install
npm start
```

Платформа доступна по адресу `http://localhost:3000`.

### Демо-аккаунты

- Администратор: `admin@robplatform.local` / `admin123`
- Пользователь: `demo@robplatform.local` / `demo123`
- Гость: вход не требуется (только просмотр каталога и демо-расчётов)

### Docker

```bash
docker-compose up
```

## Основные функции

### Пользовательские роли

| Роль | Доступ |
|---|---|
| Гость | Просмотр каталога, демо-расчёты |
| Пользователь | Создание, редактирование, сохранение проектов, расчёт, экспорт |
| Администратор | Управление каталогом, пользователями, параметрами, импорт данных |

### Экономическая модель

- **CAPEX**: оборудование + инфраструктура + ПО + интеграция + обучение + резерв
- **OPEX**: сервис + лицензии + электроэнергия + материалы + ремонт + управление
- **Годовой эффект**: сокращение затрат на труд + рост производительности
- **ROI**: накопленный эффект / инвестиции × 100%
- **TCO**: CAPEX + сумма OPEX за расчётный горизонт с учётом замены компонентов
- **Чувствительность**: вариация ключевых параметров (±10%, ±20%) для трёх факторов
- **Конфигурируемые коэффициенты**: все доли CAPEX/OPEX настраиваются вручную или через чат-помощника
- **Отраслевые поправки**: для медицины/соцсферы, сельского хозяйства, строительства, ТЭК и безопасности применяются доменные корректировки (целевой диапазон окупаемости)

### Сценарии сравнения

Платформа сравнивает:
1. Базовый сценарий (без роботизации)
2. Сценарий покупки оборудования (CAPEX + OPEX)
3. Сценарий «Роботы как услуга» (аренда / RaaS)
4. Сценарий кредита (заёмные средства)
