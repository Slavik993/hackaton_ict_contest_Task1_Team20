# Описание решения: Платформа подбора роботизированных решений

## Проблема

Организации, планирующие роботизацию (склады, аэропорты, медучреждения, производство и др.), сталкиваются с ключевыми трудностями:
- **Нет единого каталога** решений — данные разбросаны по вендорам, каталогам, презентациям
- **Сложность экономического обоснования** — нет простого инструмента для расчёта CAPEX/OPEX/ROI/срока окупаемости
- **Долгие циклы принятия решения** — экспертиза занимает недели/месяцы, а нужно «вчера»
- **Отсутствие визуализации** — стейкхолдеры не понимают, как именно будут работать роботы на их объекте

## Решение

Веб-платформа для **экспресс-предварительной оценки** роботизации объекта за 4 шага:

### 1. Выбор объекта
- 6 отраслей: Торговля, Логистика, Социальная сфера, Промышленность, Сельское хозяйство, Другое
- 7 типов объектов: склад, торговый зал, аэропорт, терминал, медучреждение, кампус/МФЦ, произвольный
- Демо-параметры под каждый тип (площадь, операции, штат, смены, зарплаты и т.д.)

### 2. Подбор решений
- Каталог **224 роботизированных решения** из каталога ФЦ БАС + открытые источники
- Фильтрация по типу объекта, типу решения (AMR, AGV, манипуляторы, сортировка, уборка, доставка, инспекция, ПО)
- Поиск по названию/вендору, сортировка по Fit (процент совпадения)
- Сравнение до 3 решений в таблице (payload, throughput, accuracy, price, ROI, срок окупаемости)
- Карточка решения с характеристиками, областями применения, источником данных

### 3. Расчёт экономики
**Входные параметры** (под каждый тип объекта — свой набор из датасетов хакатона):
- Физические: площадь, высота, пол, проезды, стеллажи
- Операционные: приёмка, отгрузка, отбор (строки/штуки), SKU, ABC-классы
- HR: штат, отборщики, погрузчики, зарплаты, ФОТ, потери времени
- Инфраструктура: WMS, ERP, конвейеры, электроснабжение, бюджет, горизонт окупаемости

**Расчётная модель** (`server/services/calculation.js`):
1. **Количество роботов** = ceil(операции_в_год / (throughput × часы_работы × доступность_0.95 × загрузка_0.85))
2. **CAPEX** = цена_оборудования × (1 + коэф.инфраструктуры + ПО + интеграции + обучения + резерва)
3. **OPEX (ежегодно)** = сервис + лицензии + электроэнергия + расходники + ремонт + управление
4. **Годовой эффект** = экономия_ФОТ + прирост_продуктивности - OPEX
5. **ROI** = (эффект × горизонт - инвестиции) / инвестиции × 100%
6. **Срок окупаемости** = первый год, когда накопленный эффект ≥ инвестиций
7. **TCO** = CAPEX + сумма OPEX за горизонт с заменой компонентов (батареи, сервоприводы и т.д.)

**Сценарии сравнения**:
- **Базовый** — без роботизации (только текущие затраты)
- **Покупка** — CAPEX + OPEX, полная собственность
- **RaaS (Robotics as a Service)** — аренда, ежемесячные платежи, сервис включён

**What-if (Чувствительность)**:
Вариация ±10% / ±20% для трёх ключевых факторов:
- Стоимость оборудования
- Объём операций
- Стоимость труда
Вывод: влияние на ROI, срок окупаемости, чистый эффект

**Экспорт**: PDF-отчёт (pdfkit) и Excel (exceljs) с таблицами, графиками, параметрами

### 4. Визуализация
- SVG-схема объекта (склад/аэропорт/больница/производство)
- Анимированные роботы (Three.js) — движение по маршрутам, погрузка/разгрузка
- KPI в реальном времени: загрузка, пропускная способность, очередь, энергопотребление
- Переключение между решениями для сравнения визуально

## Бизнес-ценность

| Метрика | Значение |
|---|---|
| Время экспресс-оценки | < 10 минут |
| Точность предварительной оценки | ±20-30% (до детальной аудиторской проверки) |
| Охват каталога | 224 решения, 10+ типов роботов, 7 типов объектов |
| Поддержка сценариев | Покупка / RaaS / Базовый |
| Экспорт | PDF (для руководства) + Excel (для фин. модели) |

## Целевые аудитории

1. **Руководители логистики/операций** — быстрое понимание «стоит ли заморачиваться»
2. **Финансовые директора / CFO** — расчёт ROI, payback, TCO для бюджета
3. **Интеграторы / вендоры** — демо-инструмент для первичной квалификации лида
4. **Консультанты** — акселерация аудита объекта

## Дополнительные фичи

- **Проекты** — сохранение/загрузка конфигураций (CRUD, авторизация JWT)
- **Админ-панель** — управление каталогом, пользователями, параметрами, импорт CSV/XLSX/PDF/JSON
- **Роли**: Гость (просмотр), Пользователь (проекты, расчёты), Админ (полный доступ)
- **Демо-вход** в 1 клик (user / admin)
- **PWA-ready** — работает офлайн (index.html + app.js + data.js + styles.css)
- **Docker** — `docker-compose up` для локального развёртывания
- **Render-ready** — `render.yaml` для бесплатного хостинга

## Ограничения (MVP)

- SQLite — не для высокой нагрузки (для продакшена нужен PostgreSQL)
- Без HTTPS на dev (на Render — авто-HTTPS)
- Парсинг каталога — разовый при запуске seed, горячий реимпорт через админку
- Визуализация — упрощённая SVG/Three.js демо, не цифровой двойник
- Без ML-рекомендаций (только rule-based фильтрация и Fit-score)
