## 1. Аннотация

Программа представляет собой веб-платформу для экспресс-предынвестиционной оценки роботизации объектов инфраструктуры: складов, терминалов, аэропортов, медицинских учреждений, производств, сельскохозяйственных, строительных, энергетических объектов, объектов ЖКХ, охраны и лесного хозяйства. Пользователь проходит четырёхшаговый сценарий: выбирает отрасль и тип объекта (в том числе через чат-помощник, распознающий тип по описанию), получает автоматически подобранные роботизированные решения из каталога 224 позиций ФЦ БАС, вводит параметры объекта и получает расчёт CAPEX, OPEX, TCO, ROI и срока окупаемости с What-if анализом чувствительности по трём ключевым факторам (±10 %, ±20 %), сравнением сценариев «Покупка», «RaaS», «Кредит», «Базовый» и итоговым отчётом в PDF/Excel. Реализованы серверный и локальный (fallback) режимы ИИ-подбора на основе rule-based ранжирования, конфигуратор коэффициентов модели, ролевой доступ, админ-панель с импортом данных (CSV, XLSX), SVG-визуализация схем объектов и сохранение проектов в БД. Интерфейс адаптивный, поддерживает сравнение до трёх решений и сохранение сессии. Программа предназначена для автоматизации предварительной экономической оценки проектов роботизации, ускорения принятия решений руководителями логистики, операций и финансовыми директорами, а также для использования интеграторами и консультантами при первичной квалификации лидов.

**Язык программирования:** JavaScript (Node.js 20.x на серверной части, ECMAScript 2020 на клиентской части), SQL (SQLite), HTML5, CSS3.
**Размер программы:** ~160 МБ (исходный код, БД и медиа-каталог); ~612 МБ полный архив с зависимостями (`node_modules`).
**Операционные системы:** Microsoft Windows 10/11, Linux (Ubuntu 20.04+, Debian 11+), macOS 11+ (Big Sur и новее); запуск через Node.js 20.x либо контейнеризацию Docker.
**Область применения:** веб-платформы для подбора роботизированных решений; программы автоматизации предынвестиционной оценки роботизации объектов инфраструктуры; системы расчёта CAPEX/OPEX/TCO/ROI и анализа чувствительности для проектов роботизации; системы поддержки принятия решений в сфере промышленности, логистики, здравоохранения, сельского хозяйства, строительства, энергетики, ЖКХ, лесного хозяйства и охраны.

## 2. Сведения об авторах и распределение ролей (4 автора)

> Подставьте реальные ФИО в поля `<ФИО_1>` … `<ФИО_4>`.

| № | Роль | ФИО | Что сделано (вклад) |
|---|---|---|---|
| 1 | **Архитектор / Тимлид** | `<ФИО_1>` | Проектирование клиент-серверной архитектуры, схемы БД SQLite, REST API (Express), JWT-аутентификации, контейнеризации (Docker, docker-compose), координация работы команды, сдача продукта на хакатоне. |
| 2 | **Backend-разработчик** | `<ФИО_2>` | Серверная логика: расчётная модель CAPEX/OPEX/TCO/ROI/срока окупаемости, сценарии «Покупка / RaaS / Кредит / Базовый», What-if анализ чувствительности, rule-based ИИ-ранжирование решений с локальным fallback, парсинг каталога ФЦ БАС (CSV) и датасетов (XLSX), экспорт PDF (pdfkit) и Excel (exceljs). |
| 3 | **Frontend-разработчик** | `<ФИО_3>` | Клиентская часть: четырёхшаговый мастер (выбор объекта → подбор решений → расчёт экономики → формальные результаты), HTML5/CSS3/Vanilla JS без тяжёлых фреймворков, адаптивная вёрстка, sticky-панель действий, чат-помощник на шаге 1 и по математической модели, SVG-визуализация схем объектов, конфигуратор коэффициентов, сохранение состояния в localStorage. |
| 4 | **Аналитик / Дата-инженер** | `<ФИО_4>` | Подготовка и нормализация каталога решений (224 позиции ФЦ БАС), сбор и структурирование датасетов объектов (склад, аэропорт, медучреждение, ферма, стройплощадка, энергообъект, охрана), настройка отраслевых поправок и доменных коэффициентов, формулирование бизнес-требований, описание ТЗ, подготовка демо-данных. |
